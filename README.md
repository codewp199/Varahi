# Varahi

> Working project name for a four-founder, local-business web design and development venture.

We are exploring practical website and digital experience services for independent local businesses. The goal is to help owners present their business clearly online and make it easier for customers to discover services, menus, and ways to get in touch.

## What this project is

This repository is intended to hold our company portfolio website and the materials needed to build and maintain it.

The initial portfolio is planned to introduce:

- The businesses and communities we aim to serve
- Website design and development capabilities
- Example concepts, clearly identified as concepts rather than client work
- Our delivery approach and contact information

## Current status

**Early draft.** The company name, positioning, service packages, and founder profiles are still being finalized. No client work, testimonials, integrations, or business results are claimed here.

## Planned implementation

The portfolio is planned as a responsive static website using Astro, TypeScript, and CSS, with deployment through GitHub Pages and GitHub Actions. These choices will be confirmed as the project files are added.

## Working principles

- Validate customer needs before promising a solution.
- Keep scope, pricing, timelines, and responsibilities clear.
- Protect customer data and use appropriate access controls.
- Label demonstrations and concept work accurately.
- Prefer maintainable, accessible, mobile-friendly implementations.

## Team collaboration

Use branches and pull requests for proposed changes so the team can review updates before they are merged. Keep decisions and unresolved questions visible in issues or project notes.
